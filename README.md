# Navi · 大学生生涯规划 Agent

**它做什么**

学生填一份问卷，系统算出他适合哪条大学路径，并讲清这条路的全部真相。

**为什么需要它**

大学生不知道有哪些路可走，也不清楚每条路的真实规则——保研看什么、何时开始、有哪些隐形门槛。这些信息散落各处、质量参差，而大学路径有硬性时间窗口，错过代价极高。

**怎么运转**

1. **填问卷** —— 约 40 道场景化题目，五档程度选择
2. **算画像** —— 确定性算法算出 8 维指标，匹配出最合适的两三条路径，并给出画像标签
3. **看真相** —— 每条路径的时间线、硬门槛、常见误区、选择它的代价
4. **继续追问** —— 针对具体问题深入

覆盖 7 条路径：保研、考研、本科就业各分本专业与跨专业，加上体制内。

**最关键的设计**

推荐结论**完全由算法算出，不由大模型生成**，模型只负责讲成学生听得懂的话。同一份问卷永远得到同一个推荐：可解释、可复现、不会编造。

**团队的核心资产**

知识库——7 条路径的真相以 Markdown 写成，标注「已核实 / 待核实」，由团队持续校对扩展，**不需要写代码**。
